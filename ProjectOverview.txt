URL Shortener System (Spring Boot + Redis + Base62)
 1. Project Overview

This project is a high-performance URL shortening service that converts long URLs into short, unique aliases using Base62 encoding, and stores mappings in Redis for fast retrieval.

It behaves like:

https://www.example.com/very/long/url → http://short.ly/aZ91k
2. Objectives
Convert long URLs into short URLs
Redirect short URL → original URL
Ensure fast lookup using Redis
Generate unique short codes using Base62
Handle high traffic efficiently
3. System Architecture
Flow:
Client → Spring Boot API → Service Layer → Redis DB
                                ↓
                         Base62 Encoder
Components:
Controller → Handles HTTP requests
Service Layer → Business logic
Redis Repository → Key-value storage
Base62 Encoder → Short code generation

5. Core Concept: Base62 Encoding

Base62 uses:

[0-9, a-z, A-Z] → 62 characters
Why Base62?
Shorter URLs
URL-safe (no special characters)
Efficient representation of numeric IDs
Example:
ID: 125
Base62 → "cb"
6. URL Generation Strategy
Option Used in Most Projects:
 Incrementing Counter + Base62
Maintain auto-increment ID
Convert ID → Base62 string
Use it as short URL key

Example:

ID = 1001
Base62 = "g7"
Short URL = /g7
7. Redis Storage Design
Key-Value Structure:
Key:   shortCode (e.g., g7)
Value: originalLongUrl
Example:
g7 → https://www.google.com/maps/...
abc → https://github.com/user/repo
 8. API Design
1. Create Short URL
POST /api/shorten
Request:
{
  "longUrl": "https://www.example.com/some/very/long/url"
}
Response:
{
  "shortUrl": "http://short.ly/g7"
}
2. Redirect URL
GET /{shortCode}
Example:
GET /g7
Action:
Fetch original URL from Redis
Redirect (HTTP 302) to original URL

 13. Sample Code Logic (Core Idea)
Base62 Encoding:
public String encode(long id) {
    String chars = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    StringBuilder sb = new StringBuilder();

    while (id > 0) {
        sb.append(chars.charAt((int)(id % 62)));
        id /= 62;
    }
    return sb.reverse().toString();
}
