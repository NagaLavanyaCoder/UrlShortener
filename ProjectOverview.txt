# URL Shortener Service (Spring Boot + Redis + Base62)

## 1. Overview
This project is a URL Shortener system that converts long URLs into short URLs and redirects users back to the original URL. It uses Spring Boot for backend development, Redis for fast key-value storage, and Base62 encoding for generating short unique codes.

---

## 2. Features
- Convert long URLs into short URLs
- Redirect short URL to original URL
- Fast lookup using Redis
- Unique short code generation using Base62
- High performance and scalable design

---

## 3. Tech Stack
- Java
- Spring Boot
- Spring Web
- Redis (In-memory database)
- Maven
- Base62 Encoding

---

## 4. Architecture Flow
Client → Spring Boot Controller → Service Layer → Redis  
                                     ↓  
                               Base62 Encoder  

---

## 5. Working Flow

### 5.1 URL Shortening
1. User sends long URL
2. System generates unique numeric ID
3. Convert ID into Base62 format
4. Store in Redis as:
   shortCode → longURL
5. Return short URL to user

---

### 5.2 URL Redirection
1. User clicks short URL
2. Extract short code
3. Fetch original URL from Redis
4. Redirect using HTTP 302

---

## 6. Base62 Encoding
Base62 uses:
0-9 + a-z + A-Z (62 characters)

Example:
ID → Base62  
125 → cb  
1001 → g7  

Purpose:
- Compact representation
- URL-safe characters
- Unique short keys

---

## 7. Redis Data Structure
Key → Value mapping:

shortCode → originalLongURL

Example:
g7 → https://google.com/maps  
abc123 → https://github.com/user/repo  

---

## 8. API Endpoints

### 8.1 Create Short URL
POST /api/shorten

Request:
{
  "longUrl": "https://example.com/very/long/url"
}

Response:
{
  "shortUrl": "http://short.ly/g7"
}

---

### 8.2 Redirect URL
GET /{shortCode}

Example:
GET /g7

Action:
Redirect to original URL (HTTP 302)

---

## 9. Components

### Service
